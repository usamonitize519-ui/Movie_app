# My Movie ❤️
Starter project for the final design: add a movie, private room, synchronized playback, chat, and WebRTC call.

Run: install Node.js 20+, then `npm install` and `npm start`. Open http://localhost:3000.

For two phones over the internet, deploy this Node/WebSocket server with HTTPS. The uploaded movie is stored on the server so both devices can load it. Camera/mic require HTTPS on phones.

This is the project source/starter; it is not yet packaged for App Store/Google Play.
